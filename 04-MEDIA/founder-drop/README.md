# Founder Media Drop

This is the intended GitHub location for curated founder media used by Z.ai browser experiments.

Recommended subfolders:

```
founder-drop/
├── characters/
├── scenes/
├── product/
├── examples/
└── video/
```

Upload **web-ready derivatives**, not the entire RAW archive.

After adding media:
1. update `../manifest.json`;
2. record provenance/rights;
3. commit;
4. send the central coordinator the new commit SHA.

For large local collections use `../INGEST-FROM-SSD.md` instead of browser uploads.
