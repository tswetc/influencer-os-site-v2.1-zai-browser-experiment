# Media Policy

## Three classes

### A. FOUNDER_MEDIA
Founder-provided visual material intended for product experiments.

May be used only according to the founder's stated rights/publication status.

### B. REFERENCE_MEDIA
Screenshots/images/videos used to study another site's mechanics or art direction.

Never present these as Influencer OS output.

### C. GENERATED_OR_DEMO_MEDIA
Images/videos created for the browser experiment.

Must state actual provenance/provider status.

## Identity continuity

One character/identity per narrative case block unless the brief explicitly requires comparison.

## Provenance

UI should distinguish:
- input reference;
- source/founder media;
- generated output;
- mock/demo output;
- external design reference.

## Git size

GitHub is the transport layer, not the permanent RAW media archive.

Commit curated web derivatives.
Keep RAW/original media on founder storage.
