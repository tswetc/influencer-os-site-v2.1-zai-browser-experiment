# Atlas Publication Gate

The review atlas is a derivative visual index of the founder SSD library.

Before pushing the atlas to this **public** experiment repository, confirm that every included logical group is acceptable for temporary public GitHub exposure.

Important:
- later making the repository private does not guarantee previously public files were never cached, cloned or mirrored;
- the inventory includes named social-handle folders and a category labelled "Семья и ребёнок";
- reference material from third parties may have different publication/reuse rights from founder-owned or generated media.

Default rule:
- metadata inventory may stay public if acceptable;
- visual atlas publication requires an explicit founder decision;
- if only part of the corpus is public-safe, publish a filtered atlas rather than the whole atlas.

After the atlas is published and reviewed, full-resolution/web-ready packs should still be limited to selected media with explicit provenance/rights metadata.
