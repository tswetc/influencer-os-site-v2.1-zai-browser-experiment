# PALE REVERIE — Regions

## Silver Shoals

Black mirror-like water, pale mineral islands, whale-rib arches, amber lamps beneath water and pearl Moon reflections.

Traversal: Mirror Step.

Memory phenomenon: reflections show states that are not currently present.

Landmark: rib-arch causeway over an apparently bottomless reflective sea.

## Lavender Manes

Lavender hills, mane-like trees/plants, visible wind rivers, translucent/glass sky-whales and pale cyan/lavender sky.

Traversal: wind currents + Moon Glide.

Memory phenomenon: wind carries fragments of voices or gestures across terrain.

Landmark: migrating sky-whale route becoming traversal path.

## Olive Light Swamp

Olive, sage and turquoise fog, giant lily pads, lime lantern organisms and cream stone faces partly submerged.

Traversal: slow water, pads, roots/vertical plants.

Memory phenomenon: faces/lanterns react to remembered identities.

Landmark: field of half-submerged monumental faces lit from below.

## Lace Cathedral

Black-violet whale-bone gothic, Lace windows/membranes, pearl light, giant organ and deep negative space.

Traversal: vertical interior, ribs, suspended membranes.

Memory phenomenon: music/organ architecture reconstructs events.

Landmark: giant organ embedded in whale-like architecture.

## Clock Cliff / Orrery

Bronze, ivory, golden linework, huge astronomical mechanisms and moments frozen as physical tableaux.

Traversal: rotating/frozen mechanisms, timed surfaces.

Memory phenomenon: time fragments and memory do not advance together.

Landmark: traversable giant orrery.

## Glass Garden

Saturated pop blue, giant liquid-chrome head, transparent structures, miniature worlds, candy-like objects and selective red/yellow/green accents.

Traversal: gravity changes and inside/outside scale shifts.

Memory phenomenon: dream logic turns memory categories into physical spaces.

Landmark: The Sleeper.

Blu should feel especially native here.

## Sea of Silence

Inverted sky, teal-black space/water, lunar fragments, vast negative space and upside-down Oriel.

Traversal: orientation uncertainty with readable control.

Memory phenomenon: memories with no surviving owner.

Landmark: Oriel suspended/inverted across the horizon.

Narrative: late-game truth region.

## Connectivity

The project should feel like one world even if technical loading boundaries exist.

Prefer authored physical transitions for important neighboring regions and special dream/ritual transitions where fiction supports them.

Fast travel is convenience, not the only proof that regions connect.

Do not force seamless streaming merely as a prestige metric if it damages quality elsewhere.
