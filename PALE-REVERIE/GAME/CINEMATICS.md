# PALE REVERIE — Cinematics & Produced Media

## In-game cinematic slots

Current planned four produced videos:

1. `intro_awakening.mp4`
   - opening awakening;
   - transition into gameplay framing.

2. `title_loop.mp4`
   - main menu / loading visual loop;
   - pearl moon / world atmosphere;
   - seamless loop.

3. `boss_warden_intro.mp4`
   - Warden of the Ebb reveal;
   - ends in gameplay handoff.

4. `ending_tide.mp4`
   - one major ending/ending-family cinematic;
   - exact ending usage can be revised with narrative implementation.

Engine fallback should exist where a missing external video would otherwise break progression.

## Cinematic quality

Desired:
- fashion-film framing;
- surreal transitions;
- high-end anime character continuity;
- realistic rain/water/light behavior;
- controlled lens effects;
- strong sound design;
- music-video-level shot rhythm.

Generated footage cannot redefine character identity or world canon merely because it looks attractive.
