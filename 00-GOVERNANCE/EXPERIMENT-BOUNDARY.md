# Experiment Boundary

This repository is a **Chat.Z.AI browser-development experiment** for Influencer OS Site V2.1.

It is deliberately separated from:
- the canonical Influencer OS product repository;
- the canonical Influencer OS site V2/V2.1 repository;
- deployment infrastructure;
- production credentials;
- production publication rights.

Any artifact produced by a Z.ai run is a candidate only.

Promotion path:

`Z.ai experiment → forensic audit → selected candidate → real Git branch → Codex/ZCode refinement → optional V2.1 integration`

Nothing moves to the canonical product automatically.
