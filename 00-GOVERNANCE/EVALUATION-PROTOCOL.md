# Evaluation Protocol

Two experiment types must remain separate.

## A. Model comparison

Keep identical:
- source commit;
- mission;
- reference set;
- media set;
- design brief;
- initial workspace condition where possible.

Change only the model.

Use this to compare GLM-5.2, GLM-5.3-Flash, and GLM-5.3.

## B. Creative exploration

Keep identical:
- product source;
- product architecture;
- mission backbone.

Allow differences in:
- design brief;
- reference set;
- visual emphasis.

## Evaluation dimensions

- source fidelity
- long-run stability
- product architecture
- visual quality
- UX depth
- code correctness
- research quality
- failure recovery
- prioritization
- MCP correctness
- real provider integration
- EN/RU quality
- responsive quality
- final packaging/export fidelity

Do not compare screenshots alone.

Every result must include enough evidence to audit what it actually read, built, tested, mocked, and exported.
