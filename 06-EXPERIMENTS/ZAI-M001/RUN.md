## Goal

Review the founder media atlas, identify strong coherent media families, and propose a master selected library for product runs.

This is NOT a product-build run.

## Input

- committed media inventory;
- committed visual review atlas;
- media policy;
- product truth;
- Wave 01 design recipes.

## Method

1. verify atlas transport and image readability;
2. review all atlas contact sheets;
3. preserve existing founder folder/shoot semantics;
4. identify identity-consistent families;
5. mark strong image/video candidates by exact atlas group + slot + SSD-relative source path;
6. avoid mixing identities inside one narrative/case family;
7. propose media packs for:
   - identity/character;
   - editorial/fashion;
   - worlds/environment;
   - product/still-life;
   - capability/workflow examples;
   - video/motion;
8. flag questionable provenance/rights rather than assuming publication permission.
