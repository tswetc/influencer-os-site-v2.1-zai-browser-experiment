# Candidate Audit Rubric

Do not judge by the founder report alone.

## Evidence first

Inspect:
- source tree;
- run manifest;
- worklog/commits;
- source reconciliation;
- tests;
- provider code;
- MCP code;
- media/provenance;
- export contents;
- screenshots/runtime.

## Dimensions

- authoritative source fidelity
- product architecture
- Character/Canon fidelity
- Prompt Lab quality
- Image/Video workflow depth
- Series/Shoot/Feed depth
- model/provider truthfulness
- MCP correctness
- auth/persistence truthfulness
- reference-research quality
- design-system coherence
- typography/grid precision
- motion quality
- media quality
- responsive/mobile quality
- EN/RU quality
- accessibility
- failure recovery
- prioritization
- regression/testing
- Git hygiene
- export freshness/portability

Record strengths and defects separately.

Do not convert the audit into a single “winner score” unless the founder later requests a non-political technical ranking.
