# ChatGPT Project Bridge

Purpose: let a fresh ChatGPT Project/chat recover Influencer OS architecture state without depending on one long conversation.

Use:
1. paste `PROJECT-INSTRUCTIONS.md` into ChatGPT Project instructions;
2. add `CURRENT-CONTEXT-HANDOFF-2026-09-25.md` to the Project files or paste it into the first chat;
3. start a fresh chat with `NEW-CHAT-BOOTSTRAP.md`;
4. the new chat must verify current GitHub HEAD before doing substantive work.

The Project instructions are intentionally durable and avoid time-sensitive SHAs/status.
The handoff file is intentionally dated and may be superseded later.

Do not put secrets, provider keys or private customer data into Project files.
