# Readymag Curated Reference Pool

Readymag Examples and Websites of the Year are used as a **curated visual research source**, not as a single aesthetic.

Primary index:
- https://readymag.com/examples/
- https://readymag.com/websites-of-the-year-2025

Why this source matters:
- Readymag's Examples are design-team curated;
- the annual awards emphasize craftsmanship, visual storytelling, impact, accessibility and performance;
- the pool contains small authorial portfolios, editorials, studios and experimental projects rather than only large commercial SaaS sites.

## Rule

The central coordinator may scout many Readymag projects.

A Z.ai run should receive only 1–2 Readymag-derived references in its final visual recipe.

Do not tell the run merely “browse Readymag and be creative.”
Give exact project URLs and exact roles.
