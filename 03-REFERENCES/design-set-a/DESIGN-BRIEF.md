# Design Set A — Editorial Dossier

## Intent

Build a complete Influencer OS product with a rigorous editorial/evidence language.

Primary influences:
- existing Influencer OS V2 Dossier DNA;
- Getty Tracing Art: photographic narrative, provenance, chapter structure, media as evidence;
- Studio K95: typographic confidence and editorial motion;
- Swiss/International typography with Scandinavian restraint.

## Emphasis

- provenance and truth visible throughout the product;
- strong grids, captions, stamps, metadata, editorial hierarchy;
- photography carries argument, not decoration;
- public pages feel authored, not SaaS;
- studios remain highly usable and dense;
- Prompt Lab becomes an evidence/assembly surface.

## Avoid

- museum site with no product;
- excessive image walls;
- generic luxury minimalism;
- huge empty hero sections;
- copying Getty/K95 skin directly.

## Invariant

This brief changes art direction, not Influencer OS semantics.
