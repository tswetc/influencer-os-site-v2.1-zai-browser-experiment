# Persona Reference Archive → Influencer OS Transfer Rules

The Persona mega archive is valuable as a **reference-research library and design-method archive**.

It is NOT Influencer OS product semantics.

## Transfer strongly

- authorial / niche / art-directed visual ambition;
- one global design grammar across different modes;
- mode-specific experiential identities;
- motion system over random effects;
- creator tools should feel like authoring, not prompt filling;
- persistent conceptual objects across modes;
- rare WOW rather than constant spectacle;
- material / light / motion can share causal rules;
- privacy/settings remain calm, literal and trustworthy;
- per-site teardown discipline;
- explicit DO NOT COPY analysis.

## High-value mappings for Influencer OS

### Global DNA
Jo Iijima, K95, R—K and related references:
use for typography, motion temperament, authorial confidence and heterogeneous-but-coherent surfaces.

### Character / visual presence
IVRESS, Gionatan Nese and fashion/editorial references:
use for Character Studio, identity evidence, case studies and media choreography.

### Creator / workbench
TouchDesigner, Nodes, Fragment:
use for Prompt Lab, Canvas, Studios, visible relationships, live preview and expert authoring.

### Cross-studio continuity
Persistent-transition references and Maria Vasilyeva's founder-highlighted gallery physics:
use to preserve Character / Scene / Asset objects across Image, Video, Compare and planning modes.

### Rare WOW
Use only where a state change, generated result, identity reveal, or handoff deserves emphasis.

## Do not transfer literally

Persona-specific Chat, Voice, Memory, History or character-presence semantics should not be imported into Influencer OS unless a concrete IOS user job requires them.

Reference aesthetics never override OS23.6 source truth.
