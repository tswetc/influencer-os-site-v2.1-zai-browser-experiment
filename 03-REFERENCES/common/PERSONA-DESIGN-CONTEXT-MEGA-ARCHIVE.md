# 0. WHAT THIS THREAD BECAME

The discussion moved from a generic request for “beautiful websites” into a much more specific design strategy for Persona:

1. Persona must **not** look like a normal SaaS dashboard.
2. Persona is currently small enough that it can be **niche, authorial, strange, art-directed, and experimental**.
3. The product has many modes, and they do **not** need to look identical.
4. Instead, every mode can have its own experiential language while still obeying one global Persona grammar.
5. The chat does **not necessarily show the character/avatar at all**.
6. Characters must not feel toy-like, collectible, gamified, or Tamagotchi-like.
7. Character presence should have another dedicated place.
8. Chat can become a **language-space** with interactive typography, state, silence, pacing, and different behavior.
9. Memory should not default to a Notion/database aesthetic; it can become a traversable personal archive.
10. History is distinct from memory.
11. “Life” should include real temporal change: time can change behavior, not merely palette.
12. Creator should borrow from authoring environments such as TouchDesigner rather than from a simplistic “prompt form.”
13. Settings/privacy should be the calmest and clearest part of the system; destructive actions must not become art experiments.
14. Cross-mode transitions should preserve conceptual objects: e.g. the *same* message can move from Chat into Memory.
15. WOW effects should be rare and state-changing, not constant decorative spectacle.
16. Sensory systems should have causality: **one state change → coordinated sound / light / motion / typography / material response**.
17. Three already selected / locked directions:
    - **IVRESS — Spin a Tale** as a major cinematic / presence reference.
    - **TouchDesigner** as a core authoring reference.
    - **Real time / day / state adaptation** as a core idea for Persona’s living environment.

The end result is no longer “a moodboard.” It is a plan to build a **Persona Reference Constitution** across P00–P12.
