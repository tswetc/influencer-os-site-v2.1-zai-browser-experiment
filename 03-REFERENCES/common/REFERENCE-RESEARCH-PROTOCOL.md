# Reference Research Protocol

Every full product run must research its assigned references before committing to final art direction.

The reference archive is a research map, not a license to copy.

For each assigned reference:

1. open the current public site/source if accessible;
2. inspect desktop and mobile behavior where possible;
3. identify exact mechanics, not vague mood;
4. record motion timing/physics when observable;
5. record typography/layout/material/image behavior;
6. identify implementation hypotheses only when evidence supports them;
7. translate the mechanic into Influencer OS product semantics;
8. write an explicit DO NOT COPY section;
9. distinguish OBSERVED / INFERRED / NOT_OBSERVED;
10. preserve product usability, accessibility and reduced-motion fallbacks.

Required synthesis format:

`REFERENCE → EXACT MECHANIC → WHY IT WORKS → IOS TRANSLATION → DO NOT COPY`

Do not spend the whole run browsing. Bound research, make an art-direction decision, then build.
