# Reference Evidence Freeze Protocol

Live reference research remains useful, but a matched experiment cannot depend only on a website that may change between runs.

For each A/B/C/D set create a frozen packet containing:

- reference name and role;
- canonical URL;
- capture timestamp;
- desktop viewport(s);
- mobile viewport where relevant;
- screenshot or short interaction evidence;
- observed layout grid;
- type family / fallback / sizing evidence where publicly inspectable;
- spacing/radius/border/material measurements;
- media crop/scale behavior;
- motion duration/easing/scroll behavior where measurable;
- OBSERVED vs INFERRED labels;
- exact Influencer OS translation;
- DO NOT COPY section.

Matched model-comparison runs receive the exact same packet.

Live browsing may supplement the packet, but it cannot silently replace it.
