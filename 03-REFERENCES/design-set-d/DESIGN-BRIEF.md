# Design Set D — Continuous Transformation

## Intent

Explore a spatial, transition-led product where conceptual objects persist between modes.

Primary influences:
- Maria Vasilyeva: founder-highlighted gallery scrolling/physics;
- Garden Eight / continuous transformation concepts;
- persistent page-transition research;
- Podium-like selected-media transition objects;
- R—K motion discipline.

## Emphasis

- the same Character, Scene, reference image or generated asset visibly persists across studios;
- selected media can become the transition object into detail/edit/video states;
- transitions clarify continuity instead of decorating navigation;
- spatial composition can change radically between public/editorial and workbench modes while retaining one motion grammar;
- mobile/reduced-motion alternatives must remain first-class.

## Avoid

- scroll hijacking that harms control;
- effects on every navigation event;
- WebGL for its own sake;
- copying Maria Vasilyeva's visual identity;
- motion that obscures state/provenance.

## Invariant

This brief changes art direction, not Influencer OS semantics.
