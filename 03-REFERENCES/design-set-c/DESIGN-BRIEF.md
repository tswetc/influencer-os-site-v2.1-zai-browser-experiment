# Design Set C — Creator Workbench

## Intent

Make the product feel like a serious authoring environment rather than a prompt form.

Primary influences:
- TouchDesigner: visible system relationships and authoring logic;
- Nodes: programming/sketching across scales;
- Fragment: constant live preview, flexible control surfaces;
- Adobe Project Graph / NodeTool principles: AI assists authoring without hiding the system.

## Emphasis

- persistent Character/Canon object across every studio;
- visible relationship between scene, world, technique, adapter and output;
- strong Prompt Lab / Canvas / Compare;
- dense expert controls with progressive disclosure;
- live preview and handoffs between Image, Video, Series/Shoot/Feed;
- public site still premium/editorial, not a dashboard homepage.

## Avoid

- forcing a node graph as the default UI;
- generic shadcn/admin dashboard;
- complexity without hierarchy;
- invisible magic-agent behavior.

## Invariant

This brief changes art direction, not Influencer OS semantics.
